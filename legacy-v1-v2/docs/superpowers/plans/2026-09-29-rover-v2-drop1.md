# Rover v2 — Drop 1 (tooling, chassis, drive modules, fit-test kit, order list) Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans (inline) to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build the `cad-v2/` toolchain and the first hardware: chassis, four drive modules with wheels, the fit-test kit, and the v2 order list, all passing the spec's checks.

**Architecture:** build123d (OpenCascade) parts are built in local frames, placed into an `Assembly` of `Item`s carrying metadata (kind, module, mass, colour, print orientation). Check modules consume the `Assembly`; `export.py` writes STEP/STL/GLB/BOM; `render/` bundles three.js and screenshots with headless Chrome.

**Tech Stack:** Python 3.12 (uv venv `cad-v2/.venv`), build123d 0.13, numpy, scipy, trimesh, pytest; FreeCAD 1.1.3 `freecadcmd` (STEP validation); Node + esbuild + three.js + Chrome headless (renders).

**Spec:** `docs/superpowers/specs/2026-09-29-rover-v2-design.md` (sections cited as §n).

## Global Constraints

- Units mm, degrees, grams; world +X forward, +Y left, +Z up, ground z = 0 (§5).
- Bed 210 × 210 × 240 mm; PETG 1.27 g/cm³ × 0.75; no print above 180 g (A3, A4).
- Overhang rule: downward faces with n_z < −0.707 must lie on the bed (z < 0.2) or be a bridge with smallest width ≤ 8 mm (A3).
- Collision: overlap ≤ 1 mm³ (A1). No allow-list for overlaps; mating features are modelled with clearance.
- No heat-set inserts, no drilled metal; M5 into spring T-nuts for frame joints, M4 + printed nut traps for printed joints (§8.3).
- Colours (§8.1): yellow `#FFCD11`, graphite `#2B2E33`, aluminium `#C9CDD2`, steel `#8A8F98`, brass `#B5A642`, black `#1A1A1A`, red `#D7191C`.
- Nothing is pushed to GitHub or published without the user's OK.
- Correction adopted from planning: the axle bolt is **M8 × 75** (spec text says 80) and the drive module has a printed **wheel cap** (hex pocket) and **three** spacer kinds (`axle_spacer_mid`, `axle_spacer_end` ×2); the spec is updated in Task 12.
