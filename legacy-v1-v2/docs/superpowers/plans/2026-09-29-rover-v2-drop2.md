# Rover v2 — Drop 2 (excavator: drum, arms, lift) Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans (inline). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add the drum excavator and lift to the rover model, at five arm poses, passing collision, print, balance and load-path checks.

**Architecture:** As drop 1 (`Item`/`Assembly`, `checks/`, `export.py`). New modules build items for a given arm pose; kinematics places arms, drum, crossbar, lever, link and carriage from the pose angle.

**Tech Stack:** unchanged. **Spec:** `docs/superpowers/specs/2026-09-29-rover-v2-design.md` §7.3, §6, §9 (drop-1 plan is `2026-09-29-rover-v2-drop1.md`).

## Global Constraints

Same as drop 1 (bed 210 × 210 × 240, 180 g cap, overhang rule, collision ≤ 1 mm³, no drilling, M4 + nut traps, colours), plus:
- **Design changes decided while modelling (the spec is synced in Task 6):** arm pivot at x = 159, **z = 145** on brackets standing on the rail tops (clears the front motor and cradle); **arm length 150**; poses **press −28°, dig −25°, level 0°, mid +20°, carry +35°**; a **centre spine** (2020 × 260) joins the rear and front cross members and carries the lift; drum end plates are **one identical part**; the link is **two plates** flanking the lever and carriage ear; arms at |y| 106..118.
- Poses used by all checks: `POSES = (-28, -25, 0, 20, 35)`.
